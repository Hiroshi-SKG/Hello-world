# Hello-world
最初のテスト

画面の中央に「Hello World!」を表示する静的ページです。HTML5 と CSS だけで動作します。

## ファイル構成

- `index.html` — ページ本体
- `styles.css` — 中央配置、文字サイズ、配色
- `README.md` — ファイル構成、動作確認、公開手順

## 動作確認

1. `index.html` をブラウザーで開きます。
2. 「Hello World!」が画面の上下左右の中央に表示されることを確認します。
3. ブラウザーの開発者ツールでスマートフォン表示（例として幅 375px）に切り替え、見出しが中央に収まり、横スクロールが発生しないことを確認します。

## GitHub Pages での公開

プルリクエストのマージ後、リポジトリの **Settings → Pages** で **Deploy from a branch** を選びます。ブランチを `main`、フォルダーを `/ (root)` に設定して **Save** を押します。公開が完了したら、同じ設定画面に表示される URL を開いて確認できます。
